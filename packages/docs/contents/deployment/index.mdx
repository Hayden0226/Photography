# Deployment

Jacky's Photography is deployed as a static SPA. The current workflow builds `apps/web/dist/`, publishes it to GitHub Pages, and mirrors the same output into the external deployment repository `Jackyhq/Photography-Web`.

The production workflow also checks out the private photo repository, standardizes incoming files, syncs published photos to Cloudflare R2, and validates the gallery with linting, type checking, unit tests, bundle-budget checks, and Playwright E2E tests.
